# Gravitas Support

## Getting Help

- **Bugs / unexpected behavior:** Open a [GitHub issue](https://github.com/udaysharmadev/Gravitas/issues) using the appropriate template
- **Benchmark submissions:** Use the "Benchmark submission" issue template
- **False completion reports:** Use the "False completion report" template
- **"Claude solved it after Gemini failed":** Use that specific template — these become future benchmark cases

## What Is Not Supported

- Antigravity API or quota questions (contact Google/Antigravity support)
- General Gemini model behavior (contact Google)
- Tasks outside Antigravity (Gravitas is Antigravity-native for v4)

## Community

Discussions happen in GitHub Issues and the Antigravity community channels. Be respectful and specific.

## Gravitas Challenge

If you have a task where baseline Gemini fails and Gravitas also fails, please submit it. Every documented failure improves the benchmark and the product.
