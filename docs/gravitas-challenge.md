# Gravitas Challenge

Submit a task that exposes a coding-agent execution failure. Wins, losses, regressions, and quota overruns are all accepted.

Every comparison fixes the task text, repository and commit, model identifier, effort, Antigravity version, Gravitas version, validator version, and run count. Include raw episodes and deterministic validator output. Infrastructure failures are marked `INVALID`.

Use the benchmark-submission issue template. Accepted cases are normalized into the manifest format, assigned a lane, and reviewed for secret or personal data before publication.

The launch premise is simple: do not trust a completion claim when the repository can check it.
